6. Flutter projesini oluşturma
flutter create ogrenci_test

Proje klasörüne geç:

cd ogrenci_test
7. Flutter projesini Firebase’e bağlama

Proje klasöründe:

flutterfire configure

Burada:

Firebase projesini seç
→ Kullanılacak platformları seç
→ Enter

İşlem sonunda şu dosya oluşur:

lib/firebase_options.dart
8. Firebase paketlerini projeye ekleme
flutter pub add firebase_core
flutter pub add cloud_firestore
9. main.dart içinde Firebase’i başlatma
import 'package:firebase_core/firebase_core.dart';
import 'package:flutter/material.dart';

import 'firebase_options.dart';

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();

  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );

  runApp(const MyApp());
}
10. Firestore’a veri ekleme
await FirebaseFirestore.instance
    .collection('ogrenciler')
    .add({
  'ad': 'Ahmet',
  'sinif': '10/A',
  'numara': 125,
});

Bu kod çalışınca Firebase’de otomatik olarak şu yapı oluşur:

ogrenciler
    └── rastgeleBelgeId
          ├── ad: "Ahmet"
          ├── sinif: "10/A"
          └── numara: 125
